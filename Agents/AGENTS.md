# Agent hub (canonical)

**Load policy on demand.** Read this file once at session start, then stop. Do not open it again this session unless it was edited. If a compaction or conversation summary replaced earlier turns and the load-table rows are not in that summary, open it once more, then stop. This applies in Cursor and Claude. If the user says `reload agents` or `recache agents`, re-read this file and any hub behavior file already opened this session, then stop again. Use the table below; open linked files only when a row applies. Full subagent bodies live in `Subagents/<name>/`. The specialist reads its own body and `user-config.md`. The parent does not open those files.

App repos: keep a pointer `AGENTS.md` at the app root whose relative path targets **this file**. That pointer loads this policy; it does **not** load hub `.cursor/` or `.githooks/`. See [README.md](../README.md#point-app-repos-at-the-hub).

## Non‑negotiables (always)

1. **Memory:** Path and max lines from gitignored `Settings/CONFIG.md`. Never commit `MEMORY.md` or `CONFIG.md`. Main agent loads memory once at session start (not Memory Steward). Memory Steward prunes to **Memory max lines**. Auto-write viable facts mid-session **in the background** (pass `memory_path` and `memory_max_lines`); show option ids only on explicit save or wrap-up. When a save lands, print `Durable memory saved to MEMORY file`. Subagents do not read the file—parent passes only task-relevant bullets.
2. **Secrets / PII:** Never commit, push, or put in PRs — use `.env` (gitignored) and `.env.example` placeholders. Details in Secrets & Git (link above).
3. **Git / GitHub (this hub repo):** Parent agent **does not** run `git` or `gh` here. Git Coordinator only; relay user choices; trust **Git Report**. On a `git` or `gh` command, read [git menus](./Rules/git-delegation/git-delegation.md), then stop. Do not open that file on any other prompt. Other git roots are not blocked by the Cursor hook — parent may run `git`/`gh` there, or pass `repo_path` to the coordinator. Ask **which repo** if unclear.
4. **Context:** Read this load table once per session, then stop. If a compaction or conversation summary drops these rows, read this file once more, then stop. This applies in Cursor and Claude. If the user says `reload agents` or `recache agents`, re-read this file and any hub behavior file already opened this session, then stop again. Parent does not open `Subagents/subagents.md` or a specialist spec, including when a User Rule lists those paths. The Task prompt tells the specialist to read its own spec and `user-config.md`. Git Coordinator is the exception: Cursor already loaded that procedure, so the Task prompt includes that spec path only after `reload agents` or `recache agents`. Do not write memory, `user-config.md`, or the user message into this file or the always-on stubs. In a Task prompt, those come after the spec path. One memory-file read per session (main agent only); trust subagent reports; details in [context discipline](./Rules/context-discipline/context-discipline.md).
5. **Local overrides:** `Rules/<name>/user-config.md` extends that rule. `Skills/<name>/user-config.md` extends that skill. `Subagents/<name>/user-config.md` extends that specialist. Read it after the shared file. Additions add. Overrides replace the matching part on this machine. Never commit `user-config.md`. `Memory/` has no `user-config.md`.
6. **Hub edits:** Do not create, edit, or delete a file in this hub unless **Enable edit** in `Settings/CONFIG.md` is `true`. Missing or any other value means disabled. Read that field immediately before a hub edit. If editing is disabled, ask **Yes** / **No** to enable it. **No** stops. **Yes** sets **Enable edit** to `true`, then makes the requested edit. `HELP` → **Enable edit** may set the flag. This applies to every agent, in Cursor and Claude. Files outside this hub are not covered.
