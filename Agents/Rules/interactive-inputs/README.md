# Interactive inputs

How a closed choice is shown: the host's clickable control when it has one, otherwise a numbered list.

Shared file: [`interactive-inputs.md`](./interactive-inputs.md).

## What lives here

Cursor, Claude, and any other app with a choice control. The option ids themselves stay in each skill's `options.md`.

## Contribute

1. Add a new closed menu as a row in [`interactive-inputs.md`](./interactive-inputs.md). Keep the ids in the skill that owns them.
2. Do not put personal preferences here. Use `user-config.md`.
