# Personality and communication

Shared rule: [`personality-communication.md`](./personality-communication.md). Loaded for tone.

## Contribute

1. Edit [`personality-communication.md`](./personality-communication.md) for tone every hub user should get.
2. Keep it short. Do not paste coding standards here. Link them.
3. Do not commit `user-config.md`.

## Local settings

Copy [`user-config.example.md`](./user-config.example.md) to `user-config.md`. That file stays on your machine. Additions extend this rule. Overrides replace the matching part for you only.
