# Coding standards (core)

Shared rule: [`coding-standards.md`](./coding-standards.md). Loaded when implementing or reviewing code.

## Contribute

1. Edit [`coding-standards.md`](./coding-standards.md) for a change every hub user should get.
2. Keep Vue-only layout and Tailwind rules in [`../coding-standards-vue/`](../coding-standards-vue/).
3. If a heading anchor changes, update links in `AGENTS.md`, the Vue rule, code-sweep, and Git Coordinator.
4. Do not commit `user-config.md`.

## Local settings

Copy [`user-config.example.md`](./user-config.example.md) to `user-config.md`. That file stays on your machine. Additions extend this rule. Overrides replace the matching part for you only.
