# Context discipline

Shared rule: [`context-discipline.md`](./context-discipline.md). Loaded when orchestrating git, memory, subagents, or large reads.

## Contribute

1. Edit [`context-discipline.md`](./context-discipline.md) for orchestration limits every hub user should get.
2. Delegation triggers stay in [`../../Subagents/subagents.md`](../../Subagents/subagents.md). Do not copy that matrix here.
3. Do not commit `user-config.md`.

## Local settings

Copy [`user-config.example.md`](./user-config.example.md) to `user-config.md`. That file stays on your machine. Additions extend this rule. Overrides replace the matching part for you only.
