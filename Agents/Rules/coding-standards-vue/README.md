# Coding standards (Vue greenfield)

Shared rule: [`coding-standards-vue.md`](./coding-standards-vue.md). Loaded for new Vue 3 + Vite work. Core standards still apply first.

## Contribute

1. Edit [`coding-standards-vue.md`](./coding-standards-vue.md) for Vue layout, Tailwind, and the Vue checklist.
2. Stack-wide rules (secrets, TypeScript, change control) belong in [`../coding-standards/`](../coding-standards/).
3. If a heading anchor changes, update the core rule and code-sweep links.
4. Do not commit `user-config.md`.

## Local settings

Copy [`user-config.example.md`](./user-config.example.md) to `user-config.md`. That file stays on your machine. Additions extend this rule. Overrides replace the matching part for you only.
